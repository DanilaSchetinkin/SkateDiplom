========================================
КОД ДЛЯ MERMAID.LIVE
========================================

ИНСТРУКЦИЯ:
1. Откройте https://mermaid.live
2. Удалите весь текст в левом окне
3. Скопируйте и вставьте один из кодов ниже
4. Справа появится диаграмма
5. Нажмите "Actions" → "PNG" для экспорта


========================================
ВАРИАНТ 1: ОСНОВНАЯ ДИАГРАММА (С ПРИМЕЧАНИЯМИ)
========================================

stateDiagram-v2
    [*] --> Новый: Клиент оформляет заказ
    
    Новый --> ВОбработке: Администратор/Сотрудник принимает
    Новый --> Отменен: Отмена заказа
    
    ВОбработке --> Отправлен: Передача в доставку
    ВОбработке --> Отменен: Отмена заказа
    
    Отправлен --> Доставлен: Клиент получил заказ
    Отправлен --> Отменен: Возврат/проблема
    
    Доставлен --> [*]
    Отменен --> [*]
    
    note right of Новый
        Заказ создан
        Номер: ORD-YYYYMMDD-XXXX
        Статус: "новый"
    end note
    
    note right of ВОбработке
        Статус: "в обработке"
        Комплектация товаров
    end note
    
    note right of Отправлен
        Статус: "отправлен"
        Передан в доставку
    end note
    
    note right of Доставлен
        Статус: "доставлен"
        Успешное завершение
    end note
    
    note right of Отменен
        Статус: "отменен"
        Заказ не выполнен
    end note

ВАРИАНТ 3: ДЕТАЛЬНАЯ ДИАГРАММА (С РОЛЯМИ)
========================================

stateDiagram-v2
    [*] --> Новый: Клиент оформляет<br/>через CartView
    
    Новый --> ВОбработке: Администратор/Сотрудник<br/>меняет статус
    Новый --> Отменен: Администратор<br/>отклоняет
    
    ВОбработке --> Отправлен: Администратор/Сотрудник<br/>передает в доставку
    ВОбработке --> Отменен: Администратор<br/>отменяет
    
    Отправлен --> Доставлен: Администратор/Сотрудник<br/>подтверждает получение
    Отправлен --> Отменен: Администратор<br/>обрабатывает возврат
    
    Доставлен --> [*]: Заказ завершен
    Отменен --> [*]: Заказ закрыт
    
    state Новый {
        [*] --> Создание
        Создание --> Сохранение: GenerateOrderNumber()
        Сохранение --> Очистка: SaveChangesAsync()
        Очистка --> [*]: CartManager.Clear()
    }

ВАРИАНТ 4: ДИАГРАММА СОСТОЯНИЙ ТОВАРА
========================================

stateDiagram-v2
    [*] --> Активный: Администратор<br/>добавляет товар
    
    Активный --> НетВНаличии: StockQuantity = 0
    НетВНаличии --> Активный: Пополнение склада
    
    Активный --> Архивный: IsActive = false
    НетВНаличии --> Архивный: IsActive = false
    
    Архивный --> [*]
    
    note right of Активный
        IsActive = true
        StockQuantity > 0
        Доступен для покупки
    end note
    
    note right of НетВНаличии
        IsActive = true
        StockQuantity = 0
        Не доступен
    end note
    
    note right of Архивный
        IsActive = false
        Снят с продажи
    end note

stateDiagram-v2

    Отменен --> [*]: Неуспешное завершение
    
    state Новый {
        note right
            Order.Status = "новый"
            Order.CreatedAt = DateTime.UtcNow
            Order.OrderNumber = ORD-YYYYMMDD-XXXX
        end note
    }

========================================
РЕКОМЕНДАЦИИ ПО ЭКСПОРТУ
========================================

1. ДЛЯ ДИПЛОМА: используйте ВАРИАНТ 1 (основная с примечаниями)
   - Хорошо читается
   - Содержит все необходимые детали
   - Профессионально выглядит

2. ДЛЯ ПРЕЗЕНТАЦИИ: используйте ВАРИАНТ 7 (компактная)
   - Простая и понятная
   - Не перегружена текстом
   - Легко воспринимается

3. НАСТРОЙКИ В MERMAID.LIVE:
   - Theme: "default" или "dark" (для темного фона)
   - Нажмите "Actions" → "PNG" для экспорта
   - Выберите высокое разрешение

4. ДЛЯ WORD:
   - Экспортируйте в PNG
   - Вставьте как изображение
   - Подпишите: "Рисунок 5 – Диаграмма переходов состояний заказа"
